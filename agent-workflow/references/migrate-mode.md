# 迁移模式（migrate）

## 目标

把旧 `agent_docs/`、`stack-workflow/` 或其他既有工作流目录迁移到新结构。

已有 `.agent-workflow/` 仅需跟进新模板结构时，使用 `upgrade` 模式，不使用本模式。

## 步骤

1. 扫描旧目录文件清单和标题结构。
2. 给出旧文件到新结构的映射方案。
3. 标注哪些内容可直接迁移、哪些需要人工确认、哪些应保留原位。
4. 等用户确认后再搬迁或整合。
5. 在新文档中标注来源。
6. 旧工作流升级到多工作项时，只补齐 `work-items/` 骨架；历史记录归属不明确时继续保留在项目级，不能猜测拆分。

## 禁止

- 禁止初始化时自动迁移。
- 禁止删除旧目录。
- 禁止丢失来源和决策背景。
