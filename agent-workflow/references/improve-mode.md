# 改进模式（improve）

## 目标

根据反复出现的问题、用户明确偏好或流程缺口，优化当前项目工作流或总 skill 模板。

## 边界

- 改当前项目 `.agent-workflow/`：可直接写入，但仍需说明改了什么。
- 改总 skill 的模板或全局规则：必须明确说明这是全局变更，并等待用户确认。
- 项目特例不能自动污染全局模板。

## 可改内容

- 任务分级和门禁。
- 用户偏好。
- 模块索引结构。
- 记录模板。
- 自检规则。
- `AGENTS.md` 工作流入口说明。

## 禁止

- 禁止无用户触发地大规模重写工作流。
- 禁止把一次偶然对话推断成长期偏好。
