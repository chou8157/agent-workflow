# 初始化模式（init）

## 目标

为单项目创建或集成标准 `AGENTS.md` 和 `.agent-workflow/` 初版。初始化只生成可信初版，不追求完整理解整个项目。

## 步骤

1. 识别项目根目录和现有入口文件。
2. 检查是否已有 `AGENTS.md`、`.agent-workflow/`、旧 `agent_docs/` 或其他工作流目录。
3. 只读扫描最低范围：README、包管理/构建配置、入口文件、主要目录、测试目录、部署/环境配置、显式引用的文档。
4. 处理 `AGENTS.md`：
   - 已存在：保留原结构，只补工作流入口、最高优先级约束和导航；大幅改写前先确认。
   - 不存在：按模板创建完整标准入口，再集成工作流入口。
5. 创建 `.agent-workflow/` 骨架和核心模板。
6. 写项目层初版：只写已确认事实和明确推断，未知内容进入 `10-project/unknowns.md`。
7. 初始化 `30-records/current-status.md`、必要日志和空的 `30-records/work-items/` 入口；不创建虚假的业务工作项。
8. 运行 `check` 自检；低风险缺失可补齐，高风险冲突只报告。

## 禁止

- 禁止一次性伪装成已理解整个项目。
- 禁止静默迁移或删除旧工作流目录。
- 禁止把外部项目规则混入当前项目，除非用户明确提供或项目显式引用。
