# 智能体工作流总入口

本目录用于让 Agent 接手、开发、排障、验证和交接当前项目时有稳定流程和可恢复上下文。

核心原则：不靠记忆，靠记录；不一次性假装懂全项目，而是在每次任务中渐进式补全事实。

## 如何阅读

1. 永远先读项目根 `AGENTS.md`。
2. 再读本文件和 `30-records/current-status.md`（项目公共状态）。
3. 涉及实际开发需求时，选择 `30-records/work-items/<ID>/`，再读该工作项的入口、当前状态和需求定义。
4. 按任务类型继续读取对应目录：
   - 流程和偏好：`00-core/`
   - 项目事实：`10-project/`
   - 具体模块：`15-modules/`
   - 质量和安全门禁：`20-gates/`
   - 历史记录：`30-records/`

## 目录说明

- `00-core/`：稳定工作方式、原则、渐进式披露和用户偏好。
- `10-project/`：项目概览、架构、规范、依赖和未知区域。
- `15-modules/`：深读模块后的轻量索引。
- `20-gates/`：质量、任务分级和高风险安全门禁。
- `30-records/`：项目公共的当前状态、进展、验证、决策、风险和待修复项。
- `30-records/work-items/`：需求、任务和缺陷的独立恢复上下文。

## 维护规则

- 默认由用户主动触发更新。
- 记录只写真实事实，推断必须标注。
- 当前状态保持简短，历史进入日志。
- 多个进行中工作项而用户未指定目标时，必须先询问，不能猜测。
