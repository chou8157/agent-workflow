# 版本与持续更新

- 产品版本标识技能程序发布，`WORKFLOW_VERSION` 标识项目结构；两者分开，不因更新程序而重建项目。
- 已有 `.agent-workflow/` 先由当前 skill 的 `upgrade_workflow.py <项目> plan` 只读识别版本、缺失项、迁移和冲突。未知或较新结构应停止写入并报告。
- 执行已获授权的 `apply-safe` 只补缺、迁移合法旧状态并生成文档建议；保留用户正文。结构已最新、迁移完成、建议已审阅分别判断。
- 项目事实仍在本地。活动追加不依赖关系库；旧活动日期缺失保留未知，不能从修改时间补造。关联可选，不随升级启用。
- 升级前结束旧写入，升级后只使用当前统一 skill 脚本。旧写入器可能覆盖新字段，不能并发混用。
- 技能程序更新应保留原运行包并核验；失败恢复或回滚只恢复技能程序，不恢复旧项目数据快照，不删除新活动和关系。
