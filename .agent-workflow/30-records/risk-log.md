# 风险记录

## 当前风险

### R001 - 尚未真实业务项目试跑

- 类型：实测不足
- 影响：当前 skill 在模拟项目中通过，但真实项目初始化、迁移和记录效果仍可能暴露模板或流程问题。
- 缓解方式：重启 Codex 后选低风险真实项目试跑 `$agent-workflow init`，只做初始化和自检，不直接迁移旧目录。
- 状态：open

### R002 - 尚未独立子智能体前向测试

- 类型：评估完整性
- 影响：当前达尔文评估为干跑和本地模拟，可能存在主会话上下文泄漏带来的乐观偏差。
- 缓解方式：后续在合适时用独立子智能体执行测试 prompts。
- 状态：open

### R003 - 当前目录不是 git 仓库

- 类型：变更追踪
- 影响：无法通过 git status、diff、commit 跟踪当前开发过程，后续回滚和审查成本更高。
- 缓解方式：如该项目需要长期维护，建议用户决定是否初始化 git 或迁移到已有版本库。
- 状态：open

### R004 - 记录脚本尚未实现

- 类型：能力边界
- 影响：`record` 目前依赖文档流程和人工编辑，记录风格仍可能漂移。
- 缓解方式：先通过真实使用观察是否需要脚本化；暂不提前过度工程化。
- 状态：watch

### R005 - 多工作项能力尚未真实项目试跑

- 类型：实测不足
- 影响：本地模板、脚本和结构验证通过，但真实项目中的任务选择、切换和记录路由仍可能暴露可用性问题。
- 缓解方式：安装版同步后选低风险真实项目试跑两个独立工作项，不启用 Git/worktree 操作。
- 状态：open

### R006 - 版本化升级尚未在真实旧项目验证

- 类型：实测不足
- 影响：模拟旧工作流已验证安全补齐和建议文件行为，但真实项目的自定义入口文档可能需要更复杂的人工合并。
- 缓解方式：安装版同步后，选一个低风险 v1 工作流先运行 `plan`，审阅建议文件后再执行 `apply-safe`。
- 状态：open
