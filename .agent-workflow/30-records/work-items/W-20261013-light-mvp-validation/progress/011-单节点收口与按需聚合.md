# 单节点收口与按需聚合

## 目标

验证活动事实能否在单节点内一次写入、重复执行不重复，并确认父节点聚合不会把子节点工作自动同步回父节点。

## 实现

- 新增实验写入器 `experiments/frontier/activity_closeout.py`。
- 收口只修改目标工作项的 `.state.json`，要求至少一条项目内证据引用、SHA-256 和行号范围。
- 同一活动 ID 和相同内容重复提交返回 `unchanged`；同一 ID 内容不同则拒绝覆盖。
- 聚合读取时重新核对证据引用哈希；证据发生变化时保留工作项状态，但将活动记录作为缺口，不继续当作可信活动。
- 新增活动覆盖、拒绝子节点、节点预算和证据变化测试；关系库只用于查询，收口本身不依赖节点身份或父子关系。

## 验证结果

在实验 fixture 中，父节点读取中间节点和叶节点的活动记录，完整结果为 `full`；拒绝叶节点后为 `partial`；节点预算限制后明确标记 `skipped`。根节点原始文件哈希保持不变。

证据：`experiments/frontier/evidence/mvp-light-closeout-aggregate-20261015-v2.json`。
