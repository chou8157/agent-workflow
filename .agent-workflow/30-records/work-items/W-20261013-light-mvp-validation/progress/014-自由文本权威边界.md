# 自由文本权威边界

## 已实现

结构化 claims 必须与原事实相等。render_verified() 只使用模型的有效引用顺序，正文重新取自原始 summary；矛盾的 text 不进入报告。

独立审查发现并修复两项漏洞：

- omitted 曾允许未知引用并可夹带换行文本；现在要求已知且唯一引用。
- 空 facts 的 partial 结果曾渲染为空；现在固定展示聚合状态及失败/跳过节点。

render_with_fallback() 在原始 JSON 或结构校验失败时，用程序固定格式展示全部原事实和覆盖缺口。它不会修补模型声明，也不会把降级当成模型通过。

## 验证边界

定向测试覆盖自由文本矛盾、未知省略引用、非法 JSON、重复键/事实/声明、输入输出预算、来源不变以及空 partial 结果。独立只读复核确认两项发现均已修复。

旧 evidence/mvp-light-agent-render-boundary-20261015.json 保留为最初合成矛盾实验，不代表最新报告格式。当前可复核展示见 evidence/mvp-light-agent-frozen-20261015/ 下的 report.md。

这证明当前受控路径不会直接采信模型 text；不证明节点内源事实语义正确，也未实现任意自然语言自动验收。当前功能仍是工作项状态展示，业务活动周报和稳定版集成尚待后续阶段。
