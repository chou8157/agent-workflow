# 001-实现与验证

## 目标

实现已生成工作流的版本化升级能力，让后续模板更新有安全、可审阅的同步路径。

## 实际变更

- 增加 `WORKFLOW_VERSION`，当前结构版本为 2。
- 增加 `upgrade_workflow.py`，支持 `status`、`plan` 和 `apply-safe`。
- 对 v1 工作流自动补齐工作项入口并写入结构版本；已有入口文档只生成独立建议文件。
- 更新升级模式、模板规范、测试 prompt 和当前项目工作流。

## 结果

- 当前项目已从无版本标记安全升级到版本 2，且没有待审阅建议。
- 模拟旧工作流升级时，既有 `AGENTS.md`、工作流入口和渐进读取规则不会被覆盖。
- 后续模板新增结构或路由规则时，项目规范要求同步更新版本、升级脚本、测试和升级说明。

## 验证

- `python3 -m pytest tests -q`：6 passed。
- `python3 -m py_compile ...`：通过。
- `python3 agent-workflow/scripts/check_workflow.py . --require-work-items --json`：通过。
- `python3 agent-workflow/scripts/upgrade_workflow.py . status --json`：当前项目版本 2，已是最新，无待审阅项。
- `python3.10 .../quick_validate.py agent-workflow`：通过。

## 后续

- 经用户确认后同步安装版，并在低风险真实项目验证 v1 到 v2 的升级建议与人工合并流程。
