# 001-实现与验证

## 目标

实现多工作项上下文能力第一期：默认任务块骨架、任务级加载与记录路由、确定性任务管理脚本、旧结构兼容和项目内测试。

## 实际变更

- 增加 `30-records/work-items/` 模板和工作项模板。
- 增加 `task_context.py`，支持创建、列出、查看和更新工作项状态。
- 更新初始化、使用、记录、自检和迁移规则，区分项目公共记录与工作项私有记录。
- 更新当前项目入口和记录，创建本工作项。
- 新增项目内测试，替代已不存在的临时测试目录依赖。

## 结果

- 新项目脚手架会创建空的工作项入口。
- 工作项可独立保存需求定义、当前状态、需求变更和分阶段进展。
- 默认自检兼容旧工作流；`--require-work-items` 可严格要求工作项入口。
- Git/worktree 操作未实现，仍为后续可选能力。

## 验证

- `python3 -m pytest tests -q`：5 passed。
- `python3 -m py_compile ...`：通过。
- `python3 agent-workflow/scripts/check_workflow.py . --require-work-items --json`：通过。
- `python3.10 .../quick_validate.py agent-workflow`：通过。
