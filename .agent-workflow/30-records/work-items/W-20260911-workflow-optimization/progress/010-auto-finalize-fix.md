# 010：开发完成自动收口能力

## 问题

原工作流只有用户明确说“记录/沉淀”时才更新文档，实际开发结束后不会默认同步工作项进展和验证记录。

## 修复

- 新增 `finalize_context.py`，收集实际变更文件、测试命令和摘要。
- 自动写入目标工作项的幂等 `progress/finalize-<fingerprint>.md`、`validation-log.md` 和当前状态摘要。
- 无 Git 时安全降级，不伪造变更事实。
- 不自动推断工作项完成，不自动修改项目级状态、Memory 或外部发布物。
- 新增 `finalize-mode.md`，明确开发/测试/状态变更/交付结束默认收口，纯讨论和阅读不触发。

## 验证

- 自动收口和幂等测试通过。
- 全量测试：`28 passed`。
- 工作流检查：`ok: true`。
- Python 脚本编译和 `git diff --check`：通过。
