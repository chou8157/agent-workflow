# 007：当前项目外部交付自托管试用

## 试用范围

在当前 `agent-workflow` 项目执行交付物完整生命周期，不涉及三个外部案例。

## 实际结果

- 生成两个阶段报告草稿并完成批准、发布。
- 修改来源文件后，已发布版本内容未发生变化；Python `hashlib.sha256` 复验通过。
- 执行 `v1 -> superseded by v2`，再执行撤回和归档，关系与状态保留正常。
- 工作流检查通过，未发现已发布交付物元数据或状态问题。

## 结论

内部事实到独立外部交付物的基本链路在当前项目可运行，发布物与内部源已实现解耦。试用中发现 `shasum` 受本机 locale 影响，最终验证改用 Python `hashlib`，因此未将环境命令异常误判为业务通过。
