# 渐进式披露规则

## 最小入口

每次进入项目，先读：

1. `AGENTS.md`
2. `.agent-workflow/README.md`
3. `.agent-workflow/30-records/current-status.md`（项目公共状态）
4. 目标工作项的 `README.md`、`current-status.md` 和 `work-item.md`

## 按需展开

- 改哪个模块，读哪个模块索引和源码。
- 涉及高风险，读安全门禁和风险记录。
- 涉及架构，读架构文档。
- 涉及规范，读项目规范。
- 详细任务历史只读取目标工作项的 `progress/`、`changes/` 和局部日志。

## 记录原则

深读模块后只记录轻量索引：代码位置、职责、入口、注意事项。详细逻辑下次修改前重新读源码确认。
