# Use five fixed top-level directories for `.agent-workflow/`

We decided to standardize the workflow skeleton around five top-level directories: `00-core/`, `10-project/`, `15-modules/`, `20-gates/`, and `30-records/`. This keeps the workflow layered and predictable while still leaving room for project-specific substructure, and it avoids the long-term drift that comes from a flat or unconstrained document layout.
