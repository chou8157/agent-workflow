# Keep the core workflow files fixed

We decided to keep a small set of workflow filenames stable inside `.agent-workflow/`: `README.md`, `workflow.md`, `current-status.md`, `progress-log.md`, `validation-log.md`, `decision-log.md`, and `risk-log.md`. This gives the skill predictable anchors for discovery and updates while still allowing each project to extend the workflow with extra files and subdirectories as needed.
